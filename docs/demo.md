# Демонстрация UI Library Orchestrator

Все команды выполняются из корня проекта. Нужны Node.js 20.20.0 и npm;
ключи API модели не требуются. При первой установке:

```bash
npm ci
npm run extract
```

`extract` создаёт локальный индекс, который читает MCP-сервер.
Если исходники компонента или документация изменились, повторите генерацию.

## API компонента

```bash
npm run orchestrate -- --docs "Button"
```

Ожидается: `Маршрут: docs`, `Статус: completed`, сведения о `Button`, его
props и источниках. Пример не создаётся; статусы его проверок — `not_run`.

## Подготовка и проверка примера

```bash
npm run orchestrate -- --example "кнопка сохранения"
```

Ожидается: `Маршрут: example`, `Статус: completed`, пример с `loading` и
`onClick`, проверки `props=passed` и `typescript=passed`. CLI покажет пути к
примеру, диагностике и истории попыток. Пример описывает сохранение и получает
функцию `onSave` от приложения.

## Отсутствующий компонент

```bash
npm run orchestrate -- --example "DatePicker"
```

Ожидается сообщение об отсутствии совпадений. Запуск имеет статус `completed`,
а проверки примера — `not_run`: данных для примера нет. В `run.json` указано
`outcome: "not_found"`.

## Замечание и доработка

```bash
npm run orchestrate:demo
```

Демонстрационная команда намеренно добавляет устаревший `isPending` в первый
вариант. Проверяющий возвращает `needs_changes`, затем подготовщик заменяет
его на `loading` и второй вариант получает `approved`. В выводе указаны пути
к обоим файлам и `attempts.json`; в истории можно увидеть замечания и изменения.

## Что показывает демонстрация

Поиск и документация поступают через локальный MCP-сервер. Порядок действий,
подготовка примера и исправление заданы кодом; модель не подключена. Маршрут
выбирает пользователь флагом, а не оркестратор по смыслу вопроса. Подготовлен
один фиксированный сценарий для `Button`. Проверка типов не запускает пример
и не оценивает его внешний вид.

Для проверки технических сценариев, в том числе ошибок и ограничения попыток:

```bash
npm run check
npm test
```
